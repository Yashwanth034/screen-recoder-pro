# Screen Recorder Pro

Screen Recorder Pro is a Chrome extension for recording a browser tab, window,
full screen, or selected screen area. It includes recording controls, webcam
overlays, audio options, live captions, screenshots, recording history, and a
built-in video editor.

## Features

- Record a tab, window, full display, or selected area
- Capture microphone, tab audio, and supported system audio
- Add a movable webcam overlay
- Pause, resume, and control recordings from a floating widget
- Display live captions while recording
- Add click effects, drawings, and text annotations
- Save screenshots during a recording
- Manage recordings in local history
- Trim, split, crop, combine, and export recordings in the built-in editor
- Recover interrupted WebM recordings when possible

## Install locally

1. Download or clone this repository.
2. Open `chrome://extensions` in Google Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the project folder containing `manifest.json`.

No build step or hosted backend is required.
