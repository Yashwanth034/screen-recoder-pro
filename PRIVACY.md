# Privacy Policy — Screen Recorder Pro

Last updated: September 27, 2026

Screen Recorder Pro is a browser extension for recording browser tabs, application windows, full screens, and user-selected page areas, with optional microphone/system audio, webcam overlays, annotations, screenshots, local recording history, and editing.

## Data the extension handles

Screen Recorder Pro may process the following data only when needed for user-requested recording features:

- Website content visible in a tab or selected recording area, including text, images, video, and other visible page content.
- User interactions such as mouse position and clicks when features such as click effects, area selection, or annotations are used.
- Audio selected by the user for a recording, such as microphone audio and supported system/tab audio.
- Webcam video when the user explicitly enables the webcam overlay.
- Recording files, screenshots, thumbnails, edit state, and extension preferences.

## How data is used

This data is used only to provide Screen Recorder Pro's user-facing recording, screenshot, annotation, history, recovery, and editing features.

## Local processing and storage

Screen Recorder Pro processes recordings locally in the browser. Recordings, screenshots, preferences, and recovery data are stored locally on the user's device using browser storage and IndexedDB as needed.

The extension does not upload recordings, screenshots, microphone audio, webcam video, browsing activity, or captured website content to developer-controlled servers.

## Data sharing and sale

Screen Recorder Pro does not sell user data.

Screen Recorder Pro does not transfer user data to third parties except where the user explicitly chooses to save, download, export, or otherwise share a recording outside the extension.

## Remote code

Screen Recorder Pro does not execute remotely hosted code. JavaScript and WebAssembly required for the extension, including the bundled RNNoise noise-suppression component, are packaged with the extension.

## Data retention and deletion

Locally stored recordings and related data remain on the user's device until the user deletes them, clears extension/browser storage, or uninstalls the extension. Users can delete saved recordings from the extension's recording library.

## Permissions

Screen Recorder Pro requests browser permissions only to provide its recording and related user-facing features, such as accessing the active tab after a user action, injecting selected-area tools, running media processing in an offscreen document, saving recordings, opening the recording controls, positioning the recording widget, and displaying recording-related notifications.

## Limited Use

Screen Recorder Pro's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed through Chrome APIs is used only to provide or improve the extension's disclosed user-facing functionality.

## Changes

If this privacy policy changes, the updated version will be published at this location with a revised “Last updated” date.
